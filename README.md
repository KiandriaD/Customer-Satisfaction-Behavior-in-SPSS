# Customer-Satisfaction-Behavior-in-SPSS
This project explores the relationships between customers and their behaviors in SPSS. The analysis was conducted to answer three core research questions using different statistical methodologies. 

Here is the Research Questions and Methodology section written into full sentences:


Question 1: To determine if a customer's location is related to whether they contacted support, a Chi-Square Test of Independence was conducted using the categorical variables "LocationSTATE" and "Support_Contacted".



Question 2: To evaluate if satisfaction scores can be predicted by age, loyalty level, and support contact, a Multiple Linear Regression was performed. This analysis used "Satisfaction_Score" as the dependent variable, with "Age," "Loyalty_Number," and "Support_Contacted_Number" serving as the predictors.





Question 3: To investigate whether satisfaction scores differ significantly between customer groups A and B, an Independent Samples T-Test was utilized to compare the means of the two groups.

Each step is recorded in the word document above.
